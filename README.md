# Halloween בשכונה

אפליקציית שכונה לליל הלואין: מפה ורשימה של בתים מפחידים, טופס הצטרפות, ואישור מנהלים. הכל בעברית, עם מצב לא-מקוון, ומוכן ללילה אחד עם בערך **1,000 משתמשים במקביל** על תוכניות חינמיות.

## למה זה מחזיק 1,000 משתמשים בחינם

הלילה עצמו הוא בעיקר **קריאה**. הילדים פותחים מפה. כמעט אף אחד לא שולח טופס באותו רגע.

| שכבה | מה קורה | למה זה זול |
| --- | --- | --- |
| `public/catalog.json` | רשימת הבתים המאושרים, קובץ סטטי | CDN של Vercel Hobby / Cloudflare Pages — אלפי בקשות לקובץ של כמה KB |
| `/api/catalog` | אותה רשימה חיה, עם `s-maxage` + `stale-while-revalidate` | הבקשה הראשונה מחשבת, השאר מה-CDN. בלי polling |
| Service Worker + IndexedDB | אחרי הביקור הראשון האפליקציה והמפה עובדות גם בלי רשת | לא נוגעים בשרת כשהוא עמוס |
| אריחי המפה | Carto Dark (חינם) עם קאש מקומי לשכונה בלבד | **בלי API key.** לא OpenStreetMap ישירות, גבולות מפה צרים כדי לא למשוך את כל העולם |
| כתיבה (טופס / מנהל) | עשרות עד מאות בקשות לפני הלילה | Vercel Hobby מספיק |

**אין רענון אוטומטי כל כמה שניות.** יש כפתור רענון, ועדכון כשחוזרים לחלון. 1,000 ילדים שמרעננים כל דקה היו שורפים את מכסת ה-Hobby. מודל הלילה: טוענים פעם אחת → ממשיכים מהקאש.

### מלאי, הקפאה, ותמונות

- **מלאי:** בעל הבית מעדכן «יש / מעט / נגמר» לכל סוג (למשל נגמר רק בלי גלוטן), וגם האם כדאי לבוא: בואו / מקושט בלי ממתקים / נגמר אל תבואו. זה נשמר ב־JSON הקטן של הקטלוג, בלי polling.
- **הקפאה:** מנהל או בעל הבית (ל־30 דק׳ / שעה / עד 22:00) מסתירים את הבית מהמפה הציבורית. במפת המנהלים הסיכה נשארת **שקופה**. אחרי הזמן שהבעלים בחר, ההקפאה יורדת לבד.
- **תמונת קישוט:** לא חובה. **עדיף קישור** לתמונה שכבר עלתה לאינטרנט (Imgur / Cloudinary / קובץ ציבורי). הקטלוג שומר רק את ה-URL — כמה בתים במפה לא משנים את גודל `catalog.json`. התמונה נטענת **רק בכרטיס הבית**, לא על הסיכות. ברשת איטית, במצב חיסכון נתונים, או כשהקטלוג רץ מהעותק הסטטי של הלילה — לא שולחים את התמונה בכלל (יש כפתור «הצג אם הרשת פנויה»). לפני לילה עמוס אפשר גם `NEXT_PUBLIC_SKIP_HOUSE_PHOTOS=1`. העלאת קובץ לשרת שלנו עובדת רק מקומית; ב-Vercel Serverless הקובץ לא נשמר.

לפני 17:00: מנהל לוחץ «הורדת catalog.json», מחליף את `public/catalog.json`, ומפרסם. משם הלילה יכול לרוץ אפילו אם מסד הנתונים המקומי לא שורד על Serverless.

### מגבלות Vercel Hobby שחשובות ללילה

- קבצים סטטיים + CDN: זה נתיב הקריאה. 1,000×20KB ≈ 20MB. רחוק מ-100GB.
- פונקציות: אל תסמכו עליהן בלילה. הקטלוג הסטטי וה-SW הם התוכנית.
- אחסון קבצים בשרת **לא נשמר** בין instances. לכן יש `data/seed.json` + ייצוא קטלוג. להרצה מלאה עם אישורים חיים אפשר `npm start` על מחשב אחד בשכונה, או להקפיא קטלוג לפני הפרסום.

## הרצה מקומית

```bash
npm install
cp .env.example .env.local
npm run dev
```

האפליקציה ב-http://127.0.0.1:43127

סיסמת מנהל ברירת מחדל: `pumpkin2026`

### בדיקת עומס (1,000 במקביל)

```bash
npm run dev
npm run stress
```

הסקריפט יורה 1,000 בקשות במקביל אל `/api/catalog` ו-`/catalog.json` ומדווח p50/p95/p99. נכשל אם יותר מ-1% שגיאות או p95 מעל 3 שניות.

```bash
CONCURRENCY=1000 BASE_URL=http://127.0.0.1:43127 npm run stress
```

## איך משתמשים

1. **מפה / רשימה** — בתים מאושרים, סינון לפי ממתקים או מצב ביקור (בואו / מקושט / נגמר), ניווט ב-Waze.
2. **הוסיפו בית** — טופס + סימון על המפה. הבית **לא מופיע** עד שמנהל מאשר. מקבלים מזהה (`בית-1847`) וקוד עריכה בן 6 ספרות.
3. **עריכת בית** — עם המזהה והקוד: מלאי לפי סוג (יש / מעט / נגמר), האם כדאי לבוא, הקפאה ל־30 דק׳ / שעה / עד 22:00 כדי לצאת בעצמכם, ותמונת קישוט אופציונלית.
4. **ניהול** — אישור / דחייה / עריכה / הקפאה. בית מוקפא נעלם מהמפה הציבורית ונשאר במפת המנהלים כסיכה שקופה.

נתוני דמו כבר ב־`data/seed.json` עם כתובות אמיתיות בשיכון ותיקים, חרוזים ונחלת גנים. שני בתים ממתינים לאישור כדי לבדוק את תור המנהלים.

## פרסום

זה אפליקציית ווב (PWA). בטלפון: «הוספה למסך הבית».

- **Vercel (חינם):** Publish / `vercel`. לפני הלילה ייצאו `catalog.json` ועדכנו את הקובץ ב-`public/`.
- **App Store / Google Play:** לא כלול בגרסה המינימלית. אפשר לעטוף אחר כך ב-[Capacitor](https://capacitorjs.com/) מאותו אתר. בינתיים PWA מכסה iOS/Android בלי חנות.

שנו שם שכונה ומרכז מפה ב-`.env.local`:

```
NEXT_PUBLIC_NEIGHBORHOOD_NAME=שם השכונה
NEXT_PUBLIC_MAP_CENTER_LAT=32.0919
NEXT_PUBLIC_MAP_CENTER_LNG=34.8112
ADMIN_PASSWORD=replace-me
```

ואז עדכנו את הגבולות ב-`src/lib/config.ts` כדי שהמפה תישאר על השכונה שלכם.

## מבנה

- `data/seed.json` — בתים התחלתיים
- `public/catalog.json` — קטלוג סטטי ללילה (נוצר ב-`npm run catalog`)
- `src/app/api/catalog` — קריאה חיה עם מטמון CDN
- `src/app/api/houses` — שליחה ועריכה לפי קוד
- `src/app/admin` — אישורי מנהל
- `public/sw.js` — קאש למעטפת, לקטלוג ולאריחי המפה
- `scripts/stress-test.mjs` — עומס 1,000 משתמשים
