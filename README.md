# בשכונה Halloween

אפליקציית שכונה לליל הלואין: מפה ורשימה של בתים מפחידים, טופס הצטרפות, ואישור מנהלים. הכל בעברית, עם מצב לא-מקוון, ומוכן ללילה אחד עם בערך **1,000 משתמשים במקביל** על תוכניות חינמיות.

## למה זה מחזיק 1,000 משתמשים בחינם

הלילה עצמו הוא בעיקר **קריאה**. הילדים פותחים מפה. כמעט אף אחד לא שולח טופס באותו רגע.

| שכבה | מה קורה | למה זה זול |
| --- | --- | --- |
| `public/catalog.json` | רשימת הבתים המאושרים, קובץ סטטי | CDN של Vercel Hobby / Cloudflare Pages — אלפי בקשות לקובץ של כמה KB |
| `/api/catalog` | רשימת הבתים החיה, עם `s-maxage` קצר + `stale-while-revalidate` | הבקשה הראשונה מחשבת, השאר מה-CDN |
| Service Worker + IndexedDB + localStorage | אחרי הביקור הראשון רשימת הבתים נשמרת בטלפון | בלי רשת או כשהשרת לא עונה מוצג העותק השמור, בלי לגעת בשרת |
| אריחי המפה | Israel Hiking Map בעברית (חינם, בלי מפתח) עם מראה כהה מקומי וקאש לשכונה | Carto / OSM France מציגים שמות רחובות באנגלית |
| כתיבה (טופס / מנהל) | עשרות עד מאות בקשות לפני הלילה | Vercel Hobby מספיק |
| מונים אנונימיים (שמרו / ביקרו) | הלב והביקור נשמרים בטלפון מיד; לשרת נשלח סיכום כל ~45 שניות | לא נוגע ב־`catalog.json` ולא נשמר בכל לחיצה |

המפה **מתרעננת לבד** כל ~15 שניות כשהחלון פתוח, וגם כשחוזרים אליו. הקריאות עוברות ב-CDN (כ־30 שניות), כך ש־1,000 טלפונים לא מפילים את השרת.

בתים חדשים נשמרים בקובץ על השרת שמריץ את האפליקציה. אם כמה אנשים שולחים יחד, הבקשות ממתינות בתור ומתבצעות **אחת אחרי השנייה** — בלי מכסת בקשות יומית.

### מלאי, הקפאה, ותמונות

- **מלאי:** בעל הבית מעדכן «יש / מעט / נגמר» לכל סוג (למשל נגמר רק בלי גלוטן), וגם האם כדאי לבוא: בואו / מקושט בלי ממתקים / נגמר המלאי. זה נשמר במסמך המשותף ונראה לכולם אחרי הרענון הבא.
- **הקפאה:** מנהל או בעל הבית (ל־30 דק׳ / שעה / עד 22:00) מסתירים את הבית מהמפה הציבורית. במצב מנהל הסיכה נשארת על המפה באותו סגול.
- **צבע סיכה:** כל הסיכות סגול האלווין עם טבעת שמנת. האימוג'י הוא לפי נושא הבית (דלעת, רפאים, ממתקים…). מלאי ופחד מופיעים בתגיות, לא בצבע הסיכה.
- **תמונת קישוט:** מעלים מהטלפון. הקובץ נדחס לכ־100KB ועולה לאירוח חינמי; ב־`catalog.json` נשמר **רק הקישור**. הילדים טוענים את התמונה מהאירוח, לא מ-Vercel — לכן 1,000 משתמשים נשארים בטווח החינמי. ברשת איטית / עותק סטטי של הלילה התמונה לא נטענת עד שלוחצים. בלי חשבון חיצוני האירוח מחזיק **72 שעות** (מספיק לסוף השבוע). לקישוט שבועות מראש, חשבון [Cloudinary](https://cloudinary.com/) חינמי (25GB) עם `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME` + `NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET`.

`public/catalog.json` נשאר עותק חירום ללילה בלי רשת. מנהל יכול להוריד אותו ולפרסם, אבל זה **לא** נדרש כדי שכולם יראו בתים חדשים.

### שמירה בטלפון, בלי רשת, והשרת לא עונה

אחרי פתיחה אחת ברשת, רשימת הבתים נשמרת במכשיר (`localStorage` + IndexedDB).

- **אין אינטרנט:** המפה והרשימה ממשיכות עם העותק השמור. מופיע «לא מקוון».
- **השרת לא עונה:** אותו דבר, עם «השרת לא עונה». רענון לא מוחק בתים שכבר נשמרו.
- **פעם ראשונה בלי רשת:** אין עותק שמור עדיין. פתחו פעם אחת כשיש קליטה.

שמירה / ביקור / סינון נשמרים בטלפון מיד, גם כשיש רשת. מונים אנונימיים לשכונה (כמה שמרו / ביקרו) נשלחים בבאץ' כל ~45 שניות — לא בכל לחיצה — כדי שלא יעמס על הלילה. פתיחת מסלול לא נספרת.

### מגבלות Vercel Hobby שחשובות ללילה

- קבצים סטטיים + CDN: זה נתיב הקריאה. 1,000×20KB ≈ 20MB. רחוק מ-100GB.
- כתיבה (טופס / מנהל) נשמרת ב־`data/db.json` מקומית. ב־Vercel מומלץ `BLOB_READ_WRITE_TOKEN` (Vercel Blob) כדי שאישורים לא יימחקו בין רענונים; בנוסף המנהל שומר גיבוי בטלפון ומשחזר אוטומטית.
- מוני שמרו/ביקרו הם קובץ נפרד (`traffic.json`), לא קטלוג הבתים. השרת מעדכן זיכרון מיד ושומר ל־Blob לכל היותר כל ~20 שניות.

## הרצה מקומית

```bash
npm install
cp .env.example .env.local
npm run dev
```

האפליקציה ב-http://127.0.0.1:43127

סיסמת מנהל ברירת מחדל: `pumpkin2026`

אם Cursor Preview מציג **403 Forbidden** על `/_next`, זה בגלל iframe עם `Origin: null`. אחרי `npm install` רץ תיקון שמרשה את זה, והמפה גם טוענת CSS מ־`/app.css`. עדיף לפתוח את הקישור ב־Chrome / Safari / בטלפון. קישור Vercel זמני נגמר אחרי כשעה אם לא מאשרים אותו («Claim»).

### חזרה כללית (לילה / שרת לא עונה)

בלי לחכות ל־31 באוקטובר, ובלי לכבות את הרשת:

- **ליל האירוע:** אחרי כניסת מנהל, תפריט → חזרה כללית. בחרו רגע (פתוח, נסגר בקרוב, וכו׳). אפשר גם לפתוח `/?rehearsal=open`.
- **השרת לא עונה:** באותו מסך, «השרת לא עונה». המפה מציגה את הרשימה ששמורה בטלפון. פתחו פעם אחת ברשת לפני כן.
- ב-Chrome: DevTools → Network → Offline זה גם בודק «אין אינטרנט». חסימת `/api/catalog` ו-`/catalog.json` בודקת «השרת לא עונה».

### הורדה להדפסה

ברשימה: כפתור ההורדה (גיליון Excel מימין לשמאל). סננו או סמנו לב קודם כדי לקבל רק את הבתים הרצויים. מנהל לוחץ על אותו כפתור ומקבל גם עמודות «שמרו» ו«ביקרו». אותו עותק של הבתים נשמר בטלפון לרשימה בלי קליטה.

## איך משתמשים

1. **מפה** — זה מסך הכניסה. רשימה בלחיצה. בסרגל: לב (שמורים), סימון «לא ביקרתי», וסינון (שעת התחלה, עם ממתקים, מתאים לילדים, נגיש, רגישויות, שכונה). כפתור «הצג תוצאות» מציג כמה בתים תואמים. כמה דירות באותה כתובת מופיעות כסיכה אחת עם מספר. לחיצה על בית פותחת כרטיס מלמטה; המפה זזה כדי שהסיכה תישאר גלויה מעל הכרטיס. תגיות הבית: ממתקים / פחד / קישוט חולקים ירוק־כתום־אדום. קישוט בארבע רמות (לא מקושט / קריצה / חגיגה / פיצוץ).
2. **הוסיפו בית** — טופס + סימון על המפה. הבית **נכנס מיד** למפה הציבורית. מקבלים קוד עריכה בן 6 ספרות לשיתוף עם המשפחה (בלי מזהה בית).
3. **עריכת בית** — מהמפה: «עריכת הבית» בכרטיס, או קישור «עריכה» בראש המסך (גם בטלפון). בוחרים בית לפי שם או כתובת. אם זה הבית שלכם במכשיר או שאתם מנהלים, נכנסים ישר לעריכת מלאי. אחרת מזינים את קוד העריכה. מלאי ממתקים (ירוק / כתום / אדום), ללא גלוטן, האם כדאי לבוא, הקפאה, ותמונת קישוט. אדום = נגמר וסוגר את הביקור.
4. **ניהול** — כניסה בסיסמה ב־`/admin`, ואז חוזרים למפה הרגילה. המנהל יכול לערוך בלי קוד, להקפיא, למחוק, ולראות את קוד העריכה. על המפה והרשימה מופיע כמה מבקרים פתוחים עכשיו — לכולם, בלי שמות ובלי מיקום. תפריט מנהל: התראות לשכונה, וחזרה כללית בנפרד. יציאה רק בלחיצה על «יציאה».
5. **התראות** — פעמון בראש המסך. בוחרים סוגים: בית חדש, עדכונים שוטפים בלילה (מלאי, סגירה), והודעות מנהלים. «הפעילו» נרשם אחרי הרשאת הדפדפן; «ביטול» סוגר בלי לשנות. אחרי הרשמה אפשר לערוך בכל עת דרך הפעמון — כל מתג נשמר מיד. כדי לכבות לגמרי במכשיר: «כבו התראות», או כבו את כל הסוגים. באייפון: «הוספה למסך הבית» ואז הפעילו.
6. **שמירה (לב) וביקור (✓)** — נשמרים בטלפון מיד. בנפרד נספרים אנונימית בשרת (בלי מיקום ובלי שם) כדי שבעלי בתים יראו כמה שמרו / ביקרו. כל מכשיר מוסיף לכל בית לכל היותר 1 (או 0 אחרי שמורידים את הסימון). פתיחת כפתור המסלול **לא** מוסיפה ספירה — זה רק תצוגה. ברשימה המספרים מופיעים על הבית שלכם; מנהל רואה אותם על כל הבתים. הספירה לשכונה מתעדכנת בערך כל דקה, לא בכל לחיצה. בסרגל: לב לשמורים, סימון «לא ביקרתי». גם **רשימת הבתים עצמה** נשמרת בטלפון אחרי הביקור הראשון.
7. **מסלול** — כפתור המסלול בסרגל. קו הליכה על הרחובות בין בניינים לפי סדר העצירות (דירות באותה כתובת = עצירה אחת) — מסביב לפארק, לא דרכו ולא במסלול רכב. מספר העצירה מעל הסיכה; ×N כתום = כמה דירות בכתובת. ניווט מכרטיס הבית. «לא ביקרתי» מסתיר בתים שסומנו כביקור.

נתוני דמו כבר ב־`data/seed.json` עם כתובות אמיתיות בשיכון ותיקים, חרוזים ונחלת גנים. שני בתים ממתינים לאישור כדי לבדוק את תור המנהלים. ב־`next dev` יש גם מוני דמו ב־`data/seed-traffic.json` (שמרו / ביקרו) כדי לראות את שורת התנועה בלי להמתין ללחיצות אמיתיות. בפרסום זה כבוי.

## פרסום

זה אפליקציית ווב (PWA). בטלפון: «הוספה למסך הבית».

- **Vercel (חינם):** הפריסה מחוברת ל־GitHub `lironm16/my-hollaween-app`. מיזוג ל־`main` ב־Cursor **לא** מפרסם לבד — צריך סנכרון ל־GitHub.
- **סנכרון אוטומטי (מומלץ):** אחרי הגדרה חד־פעמית, GitHub Actions מושך מ־Cursor כל 5 דקות ו־Vercel נפרס אוטומטית.
  1. ב־GitHub → `my-hollaween-app` → הוסיפו קובץ `.github/workflows/sync-from-cursor.yml` (העתיקו מ־`deploy/github/sync-from-cursor.yml` במאגר).
  2. Settings → Secrets → Actions: הוסיפו `ORIGIN_GIT_TOKEN` (טוקן קריאה ל־Cursor git).
  3. מעכשיו: כל merge ל־Cursor `main` מגיע ל־Vercel תוך כ~5 דקות (בלי `npm run sync:github` ידני).
- **סנכרון ידני (מיידי):** `GITHUB_TOKEN=ghp_... npm run sync:github` — מעדכן קוד באפליקציה, לא נוגע ב־`.github/` שכבר על GitHub.
- בתים חדשים נשמרים על שרת האפליקציה בתור אחד-אחד.
- **App Store / Google Play:** לא כלול בגרסה המינימלית. אפשר לעטוף אחר כך ב-[Capacitor](https://capacitorjs.com/) מאותו אתר. בינתיים PWA מכסה iOS/Android בלי חנות.

שנו שם שכונה ומרכז מפה ב-`.env.local`:

```
NEXT_PUBLIC_NEIGHBORHOOD_NAME=שם השכונה
NEXT_PUBLIC_MAP_CENTER_LAT=32.0919
NEXT_PUBLIC_MAP_CENTER_LNG=34.8112
ADMIN_PASSWORD=replace-me
# Optional. Generated automatically if omitted; set on Vercel so push keys stay stable.
# VAPID_PUBLIC_KEY=
# VAPID_PRIVATE_KEY=
# VAPID_SUBJECT=mailto:you@example.com
```

ואז עדכנו את הגבולות ב-`src/lib/config.ts` כדי שהמפה תישאר על השכונה שלכם.

## מבנה

- `data/seed.json` — בתים התחלתיים (נשפכים ל־`data/db.json` בפעם הראשונה)
- `data/db.json` — רשימת הבתים החיה על השרת
- `public/catalog.json` — קטלוג סטטי לגיבוי לא-מקוון (נוצר ב-`npm run catalog`)
- `src/app/api/catalog` — קריאה חיה עם מטמון CDN קצר
- `src/app/api/houses` — שליחה ועריכה לפי קוד
- `src/app/api/push` — הרשמה להתראות דחיפה; מנהל שולח ב־`/api/admin/push`
- `src/app/admin` — כניסת מנהל (אחרי התחברות העבודה במפה הראשית)
- `public/sw.js` — קאש למעטפת, לקטלוג ולאריחי המפה
- `scripts/stress-test.mjs` — עומס 1,000 משתמשים
