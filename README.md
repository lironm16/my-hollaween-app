# בשכונה Halloween

אפליקציית שכונה לליל הלואין: מפה ורשימה של בתים מפחידים, טופס הצטרפות, ואישור מנהלים. הכל בעברית, עם מצב לא-מקוון, ומוכן ללילה אחד עם בערך **1,000 משתמשים במקביל** על תוכניות חינמיות.

## למה זה מחזיק 1,000 משתמשים בחינם

הלילה עצמו הוא בעיקר **קריאה**. הילדים פותחים מפה. כמעט אף אחד לא שולח טופס באותו רגע.

| שכבה | מה קורה | למה זה זול |
| --- | --- | --- |
| `public/catalog.json` | רשימת הבתים המאושרים, קובץ סטטי | CDN של Vercel Hobby / Cloudflare Pages — אלפי בקשות לקובץ של כמה KB |
| `/api/catalog` | רשימת הבתים החיה, עם `s-maxage` קצר + `stale-while-revalidate` | הבקשה הראשונה מחשבת, השאר מה-CDN |
| Service Worker + IndexedDB | אחרי הביקור הראשון האפליקציה והמפה עובדות גם בלי רשת | לא נוגעים בשרת כשהוא עמוס |
| אריחי המפה | OpenStreetMap (חינם, בלי מפתח) עם מראה כהה מקומי וקאש לשכונה | Carto התחיל להציג «API key required» בלי מפתח. אפשר להחזיר Carto עם `NEXT_PUBLIC_CARTO_API_KEY` חינמי |
| כתיבה (טופס / מנהל) | עשרות עד מאות בקשות לפני הלילה | Vercel Hobby מספיק |

המפה **מתרעננת לבד** כל ~15 שניות כשהחלון פתוח, וגם כשחוזרים אליו. הקריאות עוברות ב-CDN (כ־8 שניות), כך ש־1,000 טלפונים לא מפילים את השרת.

בתים חדשים נשמרים בקובץ על השרת שמריץ את האפליקציה. אם כמה אנשים שולחים יחד, הבקשות ממתינות בתור ומתבצעות **אחת אחרי השנייה** — בלי מכסת בקשות יומית.

### מלאי, הקפאה, ותמונות

- **מלאי:** בעל הבית מעדכן «יש / מעט / נגמר» לכל סוג (למשל נגמר רק בלי גלוטן), וגם האם כדאי לבוא: בואו / מקושט בלי ממתקים / נגמר אל תבואו. זה נשמר במסמך המשותף ונראה לכולם אחרי הרענון הבא.
- **הקפאה:** מנהל או בעל הבית (ל־30 דק׳ / שעה / עד 22:00) מסתירים את הבית מהמפה הציבורית. במצב מנהל (אותה מפה) הסיכה נשארת **שקופה**.
- **תמונת קישוט:** מעלים מהטלפון. הקובץ נדחס לכ־100KB ועולה לאירוח חינמי; ב־`catalog.json` נשמר **רק הקישור**. הילדים טוענים את התמונה מהאירוח, לא מ-Vercel — לכן 1,000 משתמשים נשארים בטווח החינמי. ברשת איטית / עותק סטטי של הלילה התמונה לא נטענת עד שלוחצים. בלי חשבון חיצוני האירוח מחזיק **72 שעות** (מספיק לסוף השבוע). לקישוט שבועות מראש, חשבון [Cloudinary](https://cloudinary.com/) חינמי (25GB) עם `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME` + `NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET`.

`public/catalog.json` נשאר עותק חירום ללילה בלי רשת. מנהל יכול להוריד אותו ולפרסם, אבל זה **לא** נדרש כדי שכולם יראו בתים חדשים.

### מגבלות Vercel Hobby שחשובות ללילה

- קבצים סטטיים + CDN: זה נתיב הקריאה. 1,000×20KB ≈ 20MB. רחוק מ-100GB.
- כתיבה (טופס / מנהל) נשמרת ב־`data/db.json` מקומית. ב־Vercel מומלץ `BLOB_READ_WRITE_TOKEN` (Vercel Blob) כדי שאישורים לא יימחקו בין רענונים; בנוסף המנהל שומר גיבוי בטלפון ומשחזר אוטומטית.

## הרצה מקומית

```bash
npm install
cp .env.example .env.local
npm run dev
```

האפליקציה ב-http://127.0.0.1:43127

סיסמת מנהל ברירת מחדל: `pumpkin2026`

### בדיקת עומס (1,000 במקביל)

```bash
npm run dev
npm run stress
```

הסקריפט יורה 1,000 בקשות במקביל אל `/api/catalog` ו-`/catalog.json` ומדווח p50/p95/p99. נכשל אם יותר מ-1% שגיאות או p95 מעל 3 שניות.

```bash
CONCURRENCY=1000 BASE_URL=http://127.0.0.1:43127 npm run stress
```

## איך משתמשים

1. **מפה** — זה מסך הכניסה. רשימה בלחיצה. סינון: נגיש, ממתקים, ללא גלוטן, בתים ששמרתם, ו«לא ביקרתי». הרשימה ממוינת לפי מרחק כשיש מיקום.
2. **הוסיפו בית** — טופס + סימון על המפה. הבית **נכנס מיד** למפה הציבורית. מקבלים מזהה (`בית-1847`) וקוד עריכה בן 6 ספרות.
3. **עריכת בית** — עם המזהה והקוד: מלאי ממתקים (ירוק / כתום / אדום), ללא גלוטן, האם כדאי לבוא, הקפאה, ותמונת קישוט. אדום = נגמר וסוגר את הביקור.
4. **ניהול** — כניסה בסיסמה ב־`/admin`, ואז חוזרים למפה הרגילה. המנהל יכול לערוך בלי קוד, להקפיא, למחוק, ולראות את קוד העריכה. יציאה רק בלחיצה על «יציאה».
5. **שמירה (לב) וביקור (✓)** — נשמרים בטלפון בלבד. הסימון «ביקרתי» והפילטר «לא ביקרתי» עובדים במפה וברשימה.

נתוני דמו כבר ב־`data/seed.json` עם כתובות אמיתיות בשיכון ותיקים, חרוזים ונחלת גנים. שני בתים ממתינים לאישור כדי לבדוק את תור המנהלים.

## פרסום

זה אפליקציית ווב (PWA). בטלפון: «הוספה למסך הבית».

- **Vercel (חינם):** Publish / `vercel`. בתים חדשים נשמרים על שרת האפליקציה בתור אחד-אחד.
- **App Store / Google Play:** לא כלול בגרסה המינימלית. אפשר לעטוף אחר כך ב-[Capacitor](https://capacitorjs.com/) מאותו אתר. בינתיים PWA מכסה iOS/Android בלי חנות.

שנו שם שכונה ומרכז מפה ב-`.env.local`:

```
NEXT_PUBLIC_NEIGHBORHOOD_NAME=שם השכונה
NEXT_PUBLIC_MAP_CENTER_LAT=32.0919
NEXT_PUBLIC_MAP_CENTER_LNG=34.8112
ADMIN_PASSWORD=replace-me
```

ואז עדכנו את הגבולות ב-`src/lib/config.ts` כדי שהמפה תישאר על השכונה שלכם.

## מבנה

- `data/seed.json` — בתים התחלתיים (נשפכים ל־`data/db.json` בפעם הראשונה)
- `data/db.json` — רשימת הבתים החיה על השרת
- `public/catalog.json` — קטלוג סטטי לגיבוי לא-מקוון (נוצר ב-`npm run catalog`)
- `src/app/api/catalog` — קריאה חיה עם מטמון CDN קצר
- `src/app/api/houses` — שליחה ועריכה לפי קוד
- `src/app/admin` — כניסת מנהל (אחרי התחברות העבודה במפה הראשית)
- `public/sw.js` — קאש למעטפת, לקטלוג ולאריחי המפה
- `scripts/stress-test.mjs` — עומס 1,000 משתמשים
